# copywriting-sales.md

## Product message

Crabbie helps people find cute design/streaming assets for personal or creator needs, while also presenting illustration work and commission services.

Copy should help visitors quickly understand:

- what the artwork/asset/service is;
- who it is useful for;
- what they receive;
- whether it is available;
- what action to take next.

## Tone

Default tone:

- warm;
- cute and playful;
- clear;
- artist-owned/personal;
- concise;
- confident without aggressive sales pressure.

There are currently no owner-defined banned words or phrases.

Do not sacrifice clarity for decorative/cutesy language, especially in pricing, download availability, forms, errors, Terms, and admin labels.

## Calls to action

Prefer concrete CTAs such as:

- View project
- View asset
- Download
- View commission details
- Send commission request
- Contact

Avoid fake urgency, fake scarcity, or unsupported claims such as “best”, “guaranteed”, “only today”, or fabricated popularity metrics.

## Portfolio copy

Project copy may be expressive, but should still communicate:

- project title;
- category/context;
- what Crabbie created;
- relevant process/credits where available.

Captions should sound authored, not like mechanical numbering or placeholder labels.

## Free asset copy

Make these especially clear:

- asset type;
- file format;
- availability;
- license/credit requirement;
- what the visitor downloads.

Never show a download CTA as usable when there is no valid downloadable file.

## Commission copy

Pricing/service copy should prioritize precision over hype.

Clearly present:

- price/currency;
- availability;
- included files/deliverables;
- turnaround/delivery notes when actually defined;
- extra-character/background/rush/private/commercial rules when actually defined;
- request CTA.

Do not invent commercial terms to make the page sound more complete.

## Language source

The current CMS/admin model treats English as the primary authored content and has Vietnamese override/translation-related state.

If the localization workflow changes, update this rule file and the corresponding admin UX together so copy ownership is unambiguous.
